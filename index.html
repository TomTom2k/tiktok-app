Homelab Video Uploader

A personal, single-user tool. It renders short educational quiz videos (English vocabulary, fun facts) on the owner's home server and sends them to the owner's own TikTok inbox as drafts, using the official TikTok Content Posting API (video.upload). The owner reviews each draft in the TikTok app and posts it manually.

It is not offered to the public and has no other users.
