Privacy Policy — Homelab Video Uploader

Last updated: 20 November 2026

This tool is used only by its owner, with the owner's own TikTok account.

  • Data collected: after the owner authorizes the app, TikTok returns an access token, a refresh token and the account's open_id. Nothing else is requested.
  • Use: the tokens are used only to upload the owner's own videos to the owner's TikTok inbox as drafts.
  • Storage: tokens are stored in a single file readable only by the owner (permission 600) on the owner's private home server. They are not sold, shared or sent to any third party.
  • Other people: no data about any other TikTok user is collected, stored or processed.
  • Deletion: the owner can revoke access at any time in TikTok settings (Security → Manage app permissions); the stored token file is then deleted.

Contact: open an issue on this site's GitHub repository.
